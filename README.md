# **ТЗ Командного проекту**

### **Огляд проекту**

**Назва проекту:** Портал групи

**Мета проекту:** Створення порталу групи, де буде розміщуватися інформація про групу, новини групи, форум, електронний щоденник, події та календар подій, система опитувань, система голосувань, оголошення, матеріали, портфоліо, галерея(можно розширювати функціонал).

### **Основні функціональні вимоги:**

1. **Система автентифікації:**  
   * Реєстрація нових користувачів і вхід у існуючі акаунти.  
   * Профілі користувачів з можливістю змінювати особисті дані.  
   * В проекті повинно бути **мінімум 2 ролі доступу**: користувачі та адміністратори. Викладач та керівник проекту мають бути адміністраторами  
2. **Оголошення:**  
   * Відображення оголошень.  
   * Адміністратори можуть створювати, редагувати та видаляти оголошення.  
   * Кожен учасник може запропонувати оголошення, яке повинен схвалити адміністратор.  
3. **Форум:**  
   * Кожен зареєстрований користувач може писати повідомлення на форумі.  
   * Адміністратори та модератори можуть створювати, редагувати та видаляти гілки форуму.  
   * Дані, які надсилають користувачі, повинні валідуватись.    
4. **Електронний щоденник:**  
   * Відображення оцінок всіх учнів.  
   * Адміністратори можуть зручно додавати, редагувати та видаляти оцінки.  
5. **Система тестування:**  
   * Можливість всім зареєстрованим користувачам проходити опитування.  
   * Можливість створювати тести  
   *  Користувач може пройти опитування лише один раз(або перепройти, при цьому зберігається лише останній результат)  
   * Адміністратори та модератори можуть створювати, редагувати та видаляти тести.  
   * Адміністратори та модератори можуть переглядати результати тестувань в зручному вигляді.  
6. **Портфоліо:**  
   * Відображення кращих проектів учнів: скріншоти, посилання, файли.  
   * Всі користувачі можуть створювати, редагувати та видаляти свої портфоліо.

### **Технічні вимоги:**

* **Frontend:**  
  * Прості шаблони HTML для кожної сторінки, оформлені за допомогою CSS, можливо використовувати Bootstrap та інші зовнішні ресурси.  
  * Клієнтська взаємодія заснована на формах HTML і посиланнях.  
* **Backend:**  
  * Використання Django для створення моделей, форм, в'юшок (Class-Based Views).  
  * Використання Django sessions для управління системою опитувань.  
* **Безпека:**  
  * Застосування стандартних механізмів Django для автентифікації і захисту даних.  
* **Збереження коду:**  
  * Весь код проекту повинен зберігатись в репозиторії створеному викладачем або керівником проекту, вони надають доступи студентам для взаємодії з репозиторієм та підтримку в процесі роботи з Git.

### **Розподіл робіт**

1. **Частина Backend:**  
   * Розробка моделей і бази даних.  
   * Створення бізнес-логіки (Class-Based Views, форми).  
   * Інтеграція системи автентифікації.  
2. **Частина Frontend:**  
   * Створення і стилізація HTML-шаблонів.  
   * Забезпечення навігації між сторінками.  
3. **Частина QA/Testing:**  
   * Тестування функціональності проекту.  
   * Виявлення і усунення помилок у роботі проекту.
